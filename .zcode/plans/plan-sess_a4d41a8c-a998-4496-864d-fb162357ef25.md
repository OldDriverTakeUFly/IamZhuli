# 重新规划:cyq_perf 筹码指标主力蒸馏(数据驱动,门槛先行)

## 起点的诚实修正
我之前两次失败(主力OBI蒸馏、诱多形态)的根因,经实证勘察确认是:**moneyflow 的大单桶按订单金额分,主力拆单即可规避**——所以信号结构性偏弱。这次基于实际验证的数据能力重新规划,不再凭假设。

## 实测勘察结论(已用真实 API 调用确认,非推测)
1. **账户 5000+ 积分确认**:`top_inst`/`cyq_chips`/`cyq_perf` 均可调用。
2. **龙虎榜(top_inst)对 HS300 不可用作密集标签**:实测覆盖率 **0.26%**(72600 对中 190),73% 的 HS300 股票全年零上榜;且席位 63% 是游资营业部(东方财富拉萨),`机构专用`仅 13.7%。错误的人群 + 错误的粒度。
3. **cyq_chips/cyq_perf 是真正的突破口**:每只股每个交易日一行的**持仓成本分布**。主力拆单只能改变"订单大小",**改变不了筹码总分布**——这是结构上无法回避的信号。
4. **cyq_perf 优于 cyq_chips**:一行/股/日(`weight_avg`/`winner_rate`/`cost_5/15/50/85/95pct` 已预计算),比 cyq_chips(~100行/股/日,且有 6000 行硬截断)轻 25 倍。

## Step 1(核心门槛):cyq_perf 衍生指标的收益预测力
**新文件**:`quant/run_chip_gate.py`(复用 `run_*_gate.py` + `ic_analysis` 模式)

衍生指标(从 cyq_perf 字段计算,业界标准):
1. **90% 集中度** = `(cost_95 - cost_5) / close` — 集中度低=筹码分散,高=单峰密集
2. **70% 集中度** = `(cost_85 - cost_15) / close`
3. **获利盘比例** = `winner_rate` — 低位低获利盘+回升=洗盘后吸筹
4. **成本偏离** = `(close - weight_avg) / weight_avg` — 价格相对平均持仓成本的偏离
5. **集中度变化(20日)** = 90%集中度的 20 日差分 — 集中度收敛=主力吸筹完成

每个指标在 464 只×5 年面板(需新拉 cyq_perf,约 464 次调用)上跑:
- `rank_ic_series` + `ic_summary`:各周期(1/5/10/20日)IC/IR/t/p
- `ic_decay`:预测力衰减
- `ic_summary_by_year`:分年度稳定性
- **中性化**:复用 `ic_analysis.neutralize`(剔除行业+市值,看纯信号)

**门槛**:至少 2 个指标在 5-10 日中性化后 IC 显著(p<0.05, |IC|>0.02)。
**不达标 → 如实终止**(第三次诚实停);**达标 → 进入 Step 2**。

## Step 2(条件触发):蒸馏主力行为指纹
**前提:Step 1 通过。新文件**:`quant/behavior_distillation.py`

用通过门槛的筹码指标 +透明规则聚类,定义主力行为状态:
- **吸筹完成**:90%集中度高+收敛 + 获利盘低 + 价格平稳
- **拉升中**:成本偏离扩大 + 获利盘快速上升 + 集中度仍高
- **派发中**:高位 + 获利盘极高(>90%) + 集中度再次收敛 + 价格滞涨
- **洗盘**:集中度突降 + 获利盘急降后回升
- **静默**:其余

提取指纹:各状态强度分布、典型持续天数、**状态转移矩阵**、各状态量价特征。
**产物**:`behavior_fingerprint.json` + 人读报告 + 转移矩阵热力图。
