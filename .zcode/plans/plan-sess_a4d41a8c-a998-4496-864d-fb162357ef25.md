# Momentum 反转策略 Walk-Forward 样本外验证

## 目标(诚实界定)
回答:"夏普 0.71 是不是过拟合的假象?"

之前的回测用**全样本**做两件事:(1) 用全样本 IC 判定"反转方向";(2) 在全样本上算收益。这有轻微前视——"你怎么事先知道是反转?"walk-forward 修正这点:**每个月初只用过去 12 个月的信息决策,严格不看未来**,看样本外是否仍有效。

## 核心修正:`_factor_sign` 的前视问题
现有 `backtest.py:_factor_sign` 用全样本 IC 定方向——这是 walk-forward 要质疑的关键。
walk-forward 改为:**每个月初,用过去 12 个月的 IC 符号定当月方向**(可能某些月判为动量、某些月判为反转,如实反映"反转效应是否稳定")。

## 滚动窗口设计(12 个月训练 → 1 个月验证)

```
对每个验证月 m(从第13个月开始,覆盖2020-2023约48个月):
  1. 训练窗 = [m-12月, m-1月] 的面板数据
  2. 在训练窗算 momentum_20d_neut 对 fwd_ret_20 的 Rank IC 均值 → 定方向 sign_m
     (IC<0 → 当月按反转做 Bottom;IC>0 → 按动量做 Top)
  3. 验证:在 m 月内,按 sign_m 选股调仓,算该月实际收益(扣成本)
  4. 滑窗前进 1 个月
```

样本外:验证月收益串起来 = **纯样本外净值曲线**(每月决策只依赖过去12月,绝不触及当月及未来)。

## 评价口径(三套对照)

1. **样本外累计**:串起所有验证月 → 年化/夏普/回撤(核心指标)
2. **方向正确率**:每月 sign_m 判定 vs 该月实际最优方向,命中率(>50% 说明方向可判)
3. **vs 全样本回测**:样本外夏普 vs 全样本夏普0.71,看打折幅度
   - 经验:样本外通常为样本内的 50-70%。0.71 × 0.6 ≈ 0.42 仍为正算成功

分年度看:哪些年样本外有效、哪些失效(对照之前发现的"2021-2022 信号弱")。

## 新增文件
`quant/run_walkforward.py`
- `walk_forward_validate(panel, train_months=12, ...)`:核心滚动逻辑
  - 每月算训练窗 IC → 定方向 → 样本外调仓 → 记录
  - 复用 `_select_top_bottom` / `_turnover`(成本计算),但**不复用** `_factor_sign`(它用全样本,前视)
- 输出:样本外月收益序列、净值、指标、方向命中率、分年度

## 复用 vs 新写
- **复用**:`backtest.compute_metrics`(算夏普等)、`backtest._select_top_bottom`、`backtest._turnover`、`ic_analysis.rank_ic_series`、`plot_config`
- **新写**:滚动窗口驱动 + 每月定方向(替代全样本 `_factor_sign`)
- **不改**:现有 `backtest.py` / `run_backtest.py`(保留全样本结果作对照)

## 验证标准(诚实)
- **成功**:样本外夏普 > 0(且 >0.3 算稳健);方向命中率 >55%
- **部分成功**:夏普 >0 但 <0.3;命中率 50-55%
- **失败(过拟合证实)**:夏普 ≤0 或命中率 ≤50% → 说明全样本 0.71 主要是运气/前视

## 诚实预告
基于已知"2021-2022 信号弱",预期:
- 样本外夏普大概率**显著低于**0.71(可能 0.2-0.4)
- 方向命中率可能 55-60%(略好于随机,但不强)
- 某些月(2021-2022)会判错方向导致亏损
- 结论很可能是:"反转效应真实但弱,全样本0.71含乐观偏差,实盘预期夏普0.3左右"
- 这仍是正面结论——0.3 > 0,因子不是纯噪声
