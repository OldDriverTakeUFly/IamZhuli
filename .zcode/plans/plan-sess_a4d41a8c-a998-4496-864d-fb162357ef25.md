# 多因子合成(IC加权)+ 策略回测(多空 + 纯多头)

## 范围(按你的选择)
- **合成**:IC 加权(用样本内滚动 IC 作权重,各中性化因子 z-score 后加权)
- **回测口径**:多空对冲 + 纯多头对比基准,两个都跑
- **成本**:固定费率 0.15%/边(双边 0.30%),按每次调仓换手率计
- **输入**:直接读 `multiyear_panel_neut.parquet`(54万行,含 `*_neut` + `circ_mv` + `fwd_ret_*`),**不重新拉数据**

## IC 加权合成的关键设计(避免用未来信息)

这是最容易出错的地方——IC 加权必须严格"只用过去的数据调权",否则就是用未来收益泄漏到权重里。

**滚动 IC 加权(避免前视)**:
```
对每个调仓日 t:
  1. 回看窗口 W=60 个交易日(约3个月)
  2. 对每个单因子 k,用 [t-W, t) 内的 IC 时序算 mean_IC_k
  3. 权重 w_k = mean_IC_k / Σ|mean_IC_j|  (符号保留,按绝对值归一)
  4. 合成因子 F_i,t = Σ_k w_k × zscore(k_neut)_i,t  (横截面z-score标准化)
```
调仓周期:每 20 个交易日(与 fwd_ret_20 对齐,月度调仓)。

**冷启动处理**:前 W=60 个交易日权重不可用 → 用等权(1/3)兜底,打印提示。这样整个 5 年样本都能回测,前期是等权、后期是 IC 加权。

## 回测设计

### 多空组合(看纯选股力)
每个调仓日:
1. 按合成因子 F 对横截面排序
2. Top 50 做多、Bottom 50 做空(等权或按因子值加权,这里用等权简单)
3. 持有 20 天到下次调仓,按 fwd_ret_20 计收益
4. **多空日收益 = Top组均收益 - Bottom组均收益**
5. 累计净值 = (1+r).cumprod()

### 纯多头组合(看超额收益)
1. Top 50 做多
2. 收益含大盘 beta,需对比基准
3. **基准**:用全样本(所有464只)等权作市场基准,或直接用 fwd_ret_20 的截面均值
4. 超额收益 = Top组 - 基准

### 成本建模
每次调仓换手率 = |新持仓 - 旧持仓| 的绝对值之和 / 2(双边)。
- 单边换手 → 0.15% 成本
- 净成本 = 换手率 × 0.15% × 2(买卖各一次)
- 从调仓日收益里扣除

## 评估指标
对多空和纯多头(超额)各算:
- **年化收益**(252天年化)
- **年化波动**
- **夏普比率**(>1 算可用,>2 优秀)
- **最大回撤**
- **胜率**(正收益日比例)
- **月度平均收益**
- 与单因子(momentum 单独)对比,看合成是否真的提升

## 新增文件

### `factor_combiner.py`(新建)— 合成逻辑
- `rolling_ic_weights(panel, factor_cols, window=60)`:返回 DataFrame(date × factor)的滚动 IC 权重
- `zscore_cross_section(s)`:横截面 z-score 标准化(每日分组)
- `combine_factors(panel, factor_cols, weights_df)`:返回合成因子列 `composite`

### `backtest.py`(新建)— 回测引擎
- `RebalanceLog`:记录每次调仓的持仓、换手、成本
- `run_long_short(panel, composite_col, top_n=50, period=20, cost_rate=0.0015)`:返回日收益序列 + 净值 + 指标字典
- `run_long_only(panel, composite_col, top_n=50, period=20, cost_rate=0.0015)`:同上
- `compute_metrics(returns)`:年化收益/波动/夏普/回撤/胜率
- 成本计算:追踪上期持仓,算每次换手率

### `run_backtest.py`(新建)— 主入口
```
1. 读 multiyear_panel_neut.parquet
2. rolling_ic_weights(回看60日)→ 合成因子 composite
3. 跑多空 + 纯多头回测(含成本)
4. 同时跑 momentum 单因子作对照
5. 输出:
   - 指标汇总表(合成多空/合成多头/单因子多空/基准)
   - 净值曲线(合成多空、合成超额、单因子超额、基准)
   - 权重变化图(三个因子的滚动权重)
   - 分年度收益(看哪年表现好/差)
```

## 验证标准
- 合成因子 IC 应高于任一单因子(若 IC 加权有效)
- 多空组合年化收益为正(因 momentum 是反转,预期做空端贡献)
- 夏普比率具体数值 + 是否 >1
- 扣 0.15%/边成本后,收益是否仍为正
- 与单因子 momentum 对比,合成是否提升夏普
- 分年度看:哪年赚钱、哪年亏钱(对照 2022 熊市表现)

## 诚实预告
- 合成大概率提升 IC(三因子信息不完全重叠),但**夏普能否 >1 存疑**(单因子 IR 都<0.3)
- 扣 0.30% 双边成本(月度调仓年换手约 6-8 倍 → 年成本约 2-2.5%)后,超额收益可能被吃掉大半
- 多空组合理论好看但 A 股做空不可实操;纯多头超额才是真能用的
- 预期结论可能是:"合成因子统计上优于单因子,但扣成本后超额收益微薄,需更高频或更优组合才实战可行"
