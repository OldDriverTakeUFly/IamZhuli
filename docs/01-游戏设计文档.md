# 我是主力 (IamZhuli) — 游戏设计文档 v0.2

> 一款模拟真实股票操纵的主力视角模拟器。玩家扮演大型资本管理者，在真实盘口机制下通过吃单、挂墙、撤单诱多、对倒等真实操盘手法完成剧本任务，与可博弈的 AI 主力对手和分群体的散户市场周旋。盘外是舆论信息战，盘内是交易博弈，头顶悬着监管的剑——越高效的操纵越容易被盯上。

---

## 0. 设计决策摘要

| 维度 | 决策 | 选择理由 |
|------|------|----------|
| 定价引擎 | **完整订单簿** | 还原"吃货逐档推价"、挂单墙、撤单诱多等手法，这是主力模拟器的灵魂 |
| 游戏目标 | **剧本关卡制 + 沙盒（远期）** | POC 做关卡制，节奏清晰、教学友好；沙盒列为远期扩展 |
| 时间机制 | **实时盘口 + 暂停(只读) + 加速** | 真实盯盘紧张感 + 战术思考空间；暂停只是喘息，不给额外优势 |
| 交易规则 | **T+1** | 力求真实，以月为单位的长剧本；散户与玩家同受 T+1 约束 |
| 散户建模 | **分群体** | 盘口弹性分层，不同手法针对不同群体 |
| AI 主力 | **状态机可博弈，持仓不可见** | 真正的对手；盘口不透明靠推测，结束后可复盘看 AI 的"内心戏" |
| 关卡结构 | **单股单任务 + 难度递增** | 1 关卡 = 数个交易日，结构清晰 |
| 监管机制 | **有惩罚（交易操纵 + 信息违法）** | 操纵/隐蔽 + 信息违法的双重张力，策略深度核心来源 |
| 信息战 | **盘前/盘后舆论操纵（二期）** | 小作文、水军、信息披露、制造热点 |
| 融资融券 | **全员双向（三期）** | 玩家、AI、散户都能融资做多/融券做空 |

---

## 1. 核心体验一句话

> **以月为单位经营一个操纵剧本。盘前发小作文、盘中用吃单挂墙对倒博弈、盘后引导舆论——用全天候的信息战和交易战把股价推向目标，同时躲开监管的眼睛，结束后复盘看自己和 AI 主力的每一步博弈。**

## 2. 撮合与定价引擎（完整订单簿）

这是整个游戏的物理基础。所有玩法的"手感"都来自这里。

### 2.1 订单类型

| 订单 | 说明 | 玩家 | AI/散户 |
|------|------|------|---------|
| 限价单 | 指定价格+数量，进入订单簿排队 | ✓ | ✓ |
| 市价单 | 不指定价格，立即按最优档成交，可吃穿多档 | ✓ | ✓（部分） |
| 撤单 | 取消未成交挂单 | ✓ | ✓ |

### 2.2 撮合规则

- **价格优先、时间优先**：买单价格高者优先；同价位先挂者优先。
- **成交价 = 被动方（挂单方）价格**。当新进的主动单与挂单匹配时，按挂单方价格成交。
- **现价 = 最近一笔成交价**。价格完全由成交驱动，这就是"最高成交价为当前价"的实现。

### 2.3 价格约束

- **最小变动价位 (tick)**：0.01 元（POC 固定，可配置）。
- **涨跌停板**：±10%（基于前收盘价），到达涨跌停后该方向只能平仓不能开仓。
- POC 阶段**不做集合竞价**，开盘即连续竞价。

### 2.4 盘口结构（核心体验载体）

维护完整的买卖订单簿，对玩家展示买卖五档：

```
卖5  10.55  ████████ 800
卖4  10.54  ██████   600
卖3  10.53  ████     400
卖2  10.52  ██       200
卖1  10.51  █        100   ← 最优卖价
─────────────────────────
买1  10.50  ████     400   ← 最优买价
买2  10.49  ██████   600
买3  10.48  ████     400
买4  10.47  ██       200
买5  10.46  █        100
```

### 2.5 "吃货推价"是怎么发生的（举例）

玩家下一笔 **1500 手市价买单**：
1. 卖1 @10.51 有 100 手 → 吃掉，成交价 10.51
2. 卖2 @10.52 有 200 手 → 吃掉，成交价 10.52
3. 卖3 @10.53 有 400 手 → 吃掉，成交价 10.53
4. 卖4 @10.54 有 600 手 → 吃掉，成交价 10.54
5. 卖5 @10.55 有 200 手 → 吃掉，成交价 10.55，还剩 0 手

现价从 10.50 一路跳到 10.55——**这就是主力用资金"买上去"的过程**。

### 2.6 主力四大手法如何自然涌现

| 手法 | 在订单簿上的表现 |
|------|------------------|
| **吸筹** | 小单持续吃上方卖盘，控制节奏不让现价明显跳动 |
| **挂墙护盘/压盘** | 在某价位堆大单，制造支撑或阻力假象 |
| **撤单诱多/诱空** | 挂大单吸引跟风后撤掉，骗散户上车 |
| **对倒** | 用两个账户自买自卖制造成交量，吸引散户注意 |

这些**不需要额外设计**，只要订单簿真实，玩家自然会发明这些玩法——而 AI 和散户也自然会对此做出反应。

## 3. 市场参与者

### 3.1 玩家（主力）

- **身份**：大型资本管理者，持有一只基金/账户。
- **初始资源**：大量现金（如 1 亿）+ 关卡给定的约束。
- **可操作**：限价买/卖、市价买/卖、撤单；（二期）盘前/盘后舆论操作；（三期）融资融券。
- **目标**：完成剧本任务（见第 6 节）。
- **约束**：资金、持仓、T+1、监管关注值、关卡时间。

### 3.2 AI 主力（核心对手）

采用**状态机 + 意图识别**，持仓与成本**对玩家不可见**，靠盘口行为推测。

#### 3.2.1 AI 状态

| 状态 | 触发条件 | 行为 |
|------|----------|------|
| 观察态 | 默认/无明确信号 | 偶尔小单试探，探测盘口深浅 |
| 护盘态 | 价格跌破自身成本区 | 在下方挂大买单，托住价格 |
| 洗盘态 | 识别玩家在建仓/跟风盘变多 | 主动打压，逼浮筹恐慌止损 |
| 出货态 | 自身仓位重且价格有利 | 趁势分批卖出，甚至配合诱多 |
| 跟风态 | 识别玩家在拉升且方向确定 | 顺势加一把火，搭便车 |
| 反杀态 | 高置信度识破玩家意图 | 反向操作，吃玩家的货/砸玩家的墙 |

#### 3.2.2 AI 如何"识别玩家意图"

AI 持续监测以下信号（每个信号有置信度）：
- 某价位持续出现的买单 → **吸筹特征**
- 短时大单拉升 + 成交放大 → **推价特征**
- 同账户/关联账户对倒 → **对倒特征**（也会被监管盯上）
- 某价位反复挂撤大单 → **挂墙/诱多特征**

AI 根据信号强度在自己的状态间切换。**玩家越激进，越容易被 AI 识破和反制。**

#### 3.2.3 AI 个体属性

每个 AI 主力有：持仓与成本（会随成交变化）、策略偏好（激进/保守/狡猾）、资金量、反应灵敏度（高难度关卡更敏锐）。

### 3.3 散户群体（市场燃料）

按群体建模，**4 个群体**各有触发条件与行为，共同决定盘口的"弹性"。**散户与玩家同受 T+1 约束。**

| 群体 | 触发条件 | 行为 | 战略作用 |
|------|----------|------|----------|
| **跟风客** | 现价快速上涨（如 1 分钟 +2%） | 追涨买入 | 推波助澜，是拉升时的顺风，也是出货时的接盘侠 |
| **抄底盘** | 价格急跌到"便宜"区或破主力成本 | 逢低买入 | 提供下方承接，是下跌缓冲，也是拉升阻力 |
| **止损盘** | 价格跌破散户持仓成本 -X% | 恐慌卖出 | 加速下跌，是**洗盘的燃料** |
| **价投** | 价格偏离"内在价值" | 低买高卖，逆向操作 | 提供稳定性，节奏慢但持续 |

每个群体的参数：**数量**（群体力量）、**活跃度**（受消息面调节）、**平均持仓成本**（随成交动态更新）。

> 群体行为以**聚合挂单/成交流**的形式注入盘口，而非模拟每个个体。这样既能表现群体差异，又控制计算量。
>
> **T+1 对散户的影响**：散户今日买入次日才能卖，所以"洗盘逼止损"只能逼出**历史持仓**的止损盘，当天追涨买入的跟风客跑不掉——这让出货和洗盘的时机选择成为真正的技巧。

## 4. 消息与事件面

事件影响散户情绪与 AI 判断，是关卡节奏的调节器。

### 4.1 事件类型

- **利好**：业绩预增、大订单、政策扶持 → 散户乐观、跟风客活跃、抄底盘信心增强
- **利空**：业绩下滑、被调查、政策收紧 → 散户恐慌、止损盘活跃
- **中性**：高管变动、行业会议 → 轻微扰动

### 4.2 事件来源

- **剧本预设事件**：关卡设计的核心节奏点（如第 3 个交易日突发利空考验玩家护盘）。
- **随机事件**：增加不确定性，避免每局可背诵。
- **（二期）玩家制造的舆论事件**：见第 9 节信息战。

事件通过修改各散户群体的**活跃度/情绪参数**起作用。

## 5. 监管机制（策略深度的命门）

### 5.1 监管关注值 (Regulatory Heat)

累积指标，从 0% 开始。

**一期（交易操纵类）**：

| 行为 | 关注值增幅 | 说明 |
|------|-----------|------|
| 对倒（自买自卖） | 大 | 最容易被识别的操纵 |
| 虚假挂单（大单挂上又撤） | 中 | Wash order 特征 |
| 短时暴涨暴跌（日内 ±X%） | 中 | 异常波动 |
| 大单成交占比过高 | 小 | 持续异常会被注意 |
| 频繁撤单 | 小 | 累积才会触发 |

**二期新增（信息违法类）**：

| 行为 | 关注值增幅 | 说明 |
|------|-----------|------|
| 发布虚假小作文 | 中-大 | 散布虚假信息 |
| 水军刷帖被举报 | 小-中 | 累积举报触发 |
| 蹭热点误导（假 AI 概念等） | 中 | 误导性陈述 |

### 5.2 惩罚阶梯

| 关注值 | 后果 |
|--------|------|
| 30% | 问询函（警告，无实质损失） |
| 60% | 重点关注（小额罚款，资金减少） |
| 80% | 立案调查（大额罚款 + 持仓操作受限） |
| 100% | 强制平仓 + **关卡失败** |

### 5.3 关注值衰减

- 一段时间不违规，关注值**缓慢下降**——给玩家"低调做人、等待风头过去"的空间。
- 这创造了**节奏张力**：激进操作 → 风险累积 → 蛰伏冷却 → 再出手。

## 6. 关卡设计（单股单任务 + 难度递增）

### 6.1 关卡构成

每个关卡包含：
- **一只股票**：内在价值、流通盘、历史价格走势、市场认知
- **一个明确目标**（剧本）
- **约束条件**：资金上限、时间限制、监管红线、成本要求
- **难度参数**：AI 强度、散户群体构成、事件频率
- **时间跨度**：**30 个交易日**（详见第 7 节时间系统）
- **历史背景**：开局提供一段**历史 K 线**作为背景，便于玩家判断当前价位高低
- **观察期机制**：玩家**不必立即建仓**，可坐视 AI 与散户先把股价走到自己认可的位置再入场——代价是消耗有限的 30 天时间

### 6.2 目标（剧本）类型

| 剧本 | 典型目标 | 考验 |
|------|----------|------|
| 拉升出货 | 股价从 X 拉到 Y，并在高位出货 N% | 推价 + 出货节奏 |
| 护盘 | 利空轰炸下维持股价 ≥ X | 守势、资金管理 |
| 建仓吸筹 | 不引起注意地建仓 N% | 隐蔽、耐心 |
| 洗盘再拉 | 打压到 X 逼散户止损，再拉回 | 制造恐慌 + 接回 |
| 逆向博弈 | 对抗一个强大对手主力 | 纯博弈 |

### 6.3 难度递增曲线（建议）

| 阶段 | AI | 散户 | 监管 | 事件 |
|------|----|------|------|------|
| 关卡 1（教程） | 无 | 软弱、量少 | 几乎不触发 | 无 |
| 关卡 2-3 | 弱 AI（反应慢、策略单一） | 普通 | 宽松 | 少 |
| 关卡 4-6 | 中 AI（会洗盘/护盘） | 复杂、量大 | 正常 | 偶发 |
| 关卡 7+ | 强 AI（狡猾、会反杀） | 活跃、群体均衡 | 严格 | 频繁 |

### 6.4 关卡评分（三星制）

- ⭐ 达成基本目标（如价格到位）
- ⭐⭐ 效率优秀（成本低于阈值 / 时间更短）
- ⭐⭐⭐ 操纵优雅（监管关注值全程低位）+ 额外约束达成

三星制鼓励玩家**不止于通关，还要操纵得"漂亮"**，提升重玩价值。

### 6.5 关卡失败与重试

- **失败条件**：监管关注值达 100%（强制平仓）/ 时间耗尽未达成目标 / 资金亏光。
- **重试**：**允许重试**，重试时**完全重置**关卡状态（持仓、资金、监管关注值、股价、AI 状态、散户状态、已过时间全部归零到关卡初始）。
- **结业评价**：关卡完成（无论成功或失败后放弃），由**AI 教练**给出整体操作的点评与结业评价（如对吸筹节奏、监管规避、出货时机的点评）。教学不在 POC 阶段做实时引导，仅做事后总结。

## 7. 时间系统

### 7.1 关卡总时长

- **一个关卡 = 30 个交易日**（约对应一个"月级别"操纵剧本）。
- 30 天是有限的战略资源：观察期消耗天数 = 留给操盘的天数减少，玩家需在"等更好的入场点"与"留足操盘时间"间权衡。

### 7.2 时间框架：tick 预算制

> 一个交易日不绑定固定的真实分钟数，而是等于**固定数量的决策 tick**。盘口在每个 tick 推进时演化，玩家完全控制推进速度。

- **tick**：游戏时间最小推进单位。每个 tick 内，撮合引擎处理新订单、散户群体生成挂单/成交流、AI 评估并决策。
- **玩家节奏控制**：
  - **暂停（只读）**：冻结时间，可看盘思考，**不可下单**（不给额外优势）。
  - **1x**：正常推进，关键博弈时刻用。
  - **加速（2x / 4x / 8x）**：吸筹等待、行情平淡时跳过 tick。
- **POC 初始参数（可调）**：
  - 每个交易日竞价时段 = **约 300 tick**（一个 tick 约对应真实盘口 1 分钟的演化量，4 小时竞价浓缩）。
  - 玩家平均在单日竞价花 **5-10 分钟真实时间**（关键日 1x 细操作，平淡日加速）。
  - 30 天关卡全程 1x 约 **2.5-5 小时**，实际体感因加速而更短。
- 加速档不改变 AI 决策逻辑，只改变 tick 推进频率；AI 在每个 tick 仍正常评估（避免"加速时 AI 变笨"的漏洞）。

### 7.3 日内阶段

一个交易日按真实 A 股节奏切分（POC 简化为连续竞价，无集合竞价）：

```
[盘前] → [开盘竞价(连续)] → [午间休市(可加速)] → [午后竞价(连续)] → [收盘] → [盘后]
```

- 盘前/盘后：POC 阶段为空白时段，直接跳过（为二期信息战预留接口）。
- 午间休市：盘口暂停，可加速或暂停。

### 7.4 日间结构（T+1 月级别剧本）

```
[交易日1] 盘前→盘中→盘后 → [一键跳过休市] → [交易日2] 盘前→... → [交易日30]
```

- 一个关卡 = 30 个交易日，**日间（休市时段）一键跳过**，直接进入下一交易日盘前。
- **T+1 规则**：当日买入的筹码次日才能卖出（玩家、AI、散户同此规则）。这让"今天吸的筹，明天才能用来对倒或砸盘"，逼出真实操盘节奏。
- **每日开盘价**：POC 阶段以前收盘价为开盘基准，首笔成交即为当日现价起点。

## 8. 复盘系统（核心爽点之一）

> 玩家在盘中看不到 AI 的持仓与意图，靠盘口推测博弈。**关卡结束后提供完整复盘**，让玩家享受"原来 AI 当时在护盘/挖坑/跟风"的恍然大悟感。

### 8.1 复盘内容

- **时间轴回放**：可拖动时间轴，回看任意时刻的盘口快照。
- **参与者视角**：切换查看玩家/AI/各散户群体的持仓、成本、资金随时间变化。
- **AI 内心独白**：以**文字日志**形式呈现每个时间点 AI 的状态（观察/洗盘/反杀…）、识别到的玩家信号、做出的决策理由。类似一份"操盘日记"。
- **关键事件标注**：自动标记"玩家第一次吃货推价""AI 识破并反杀""监管问询"等节点。
- **成交明细回溯**：每笔成交的买卖双方身份（复盘时可见，盘中不可见）。

### 8.2 技术要求

- 引擎需**完整记录每个 tick 的盘口状态 + 所有参与者决策 + AI 推理过程**到回放数据。
- 这是 POC 就要做的（复盘是验证"AI 真的在博弈"的关键，没有复盘 AI 像随机数）。

## 9. 信息战（二期 — 盘前/盘后舆论操纵）

> 盘中是交易博弈，盘前盘后是信息战。作为主力，操纵的不只是订单簿，还有散户的情绪与认知。

### 9.1 信息战手段（4 种）

| 手段 | 时机 | 效果 | 成本 | 监管风险 |
|------|------|------|------|----------|
| **发布小作文/新闻** | 盘前/盘后 | 一次性大幅调整散户情绪（利好/利空） | 高（现金） | 高（虚假信息违法） |
| **雇佣水军** | 持续 | 缓慢持续影响散户情绪，需维持 | 低（持续支出） | 中（累积举报） |
| **披露/隐匿真实信息** | 盘前/盘后 | 选择性披露公司真实利好/利空 | — | 高（违规披露） |
| **制造热点/事件** | 盘前/盘后 | 蹭概念（如假 AI 合作）推高关注度 | 中 | 中（误导性陈述） |

### 9.2 信息战与盘口的联动

- 信息战效果**不直接改价**，而是改变散户各群体的**活跃度/情绪参数**，从而在次日开盘和盘中体现为盘口挂单/成交的变化。
- 例如：盘后发利好小作文 → 次日开盘跟风客活跃度暴增 → 开盘易冲高（玩家可借机出货）。

### 9.3 舆论资源系统（二期）

- 玩家有"舆论资源/水军网络"等级，影响信息战效果上限。
- 升级舆论网络需花费现金或满足关卡条件。

## 10. 融资融券（三期 — 双向交易）

### 10.1 核心机制

- **融资（做多）**：借钱买入，放大收益与风险，需支付利息，有维持担保比例要求。
- **融券（做空）**：借券卖出 → 价格下跌后买回还券，赚取差价。

### 10.2 做空闭环（关键设计）

```
借券(支付保证金) → 高位卖出(获得现金) → [砸盘/等待下跌] → 低位买回 → 还券 + 利息 → 结算盈亏
```

### 10.3 全员参与

- 玩家、AI 主力、散户群体都可融资融券（参数化，各群体参与度不同）。
- 融资融券**余额有限**：全市场可借资金/券有上限，先到先得。
- 这让市场立体化：高位融券做空也能赚钱，主力不必只做多。

### 10.4 新增风险维度

- **爆仓**：担保比例不足被强制平仓。
- **逼空**：做空者过多时，主力反向拉升逼空头止损买回，加速上涨（经典逼空行情）。

## 12. 核心玩法循环

```
剧本下达目标（如：吸筹→拉升→出货，跨数个交易日）
        │
        ▼
  暂停(只读)，观察盘口与参与者格局，制定多日计划
        │
        ▼
┌───→ 每个交易日的循环：
│      ├─ 盘前(二期)：信息战布局
│      ├─ 盘中：实时交易博弈（可暂停思考）
│      │    ├─ 吸筹：小单慢吃，盯监管值
│      │    ├─ 应对：跟风客进场 / AI 洗盘打压
│      │    ├─ 拉升：分批吃穿卖档，避免被监管
│      │    ├─ 出货：高位挂卖 + 诱多，分批跑
│      │    └─ 应对突发事件（利空 / 对手反杀）
│      ├─ 盘后(二期)：舆论引导次日
│      └─ T+1 约束：今日买的明日才能动
│      │
│      ▼
│   盘口逐档跳动，散户/AI 实时反应
│      │
└──── 监管关注值累积/衰减，动态权衡
        │
        ▼
   达成目标 → 三星评分 → 复盘回放 → 解锁下一关
```

### 12.1 策略张力点（好玩的地方）

1. **监管 vs 操纵效率**：想快速拉升就得猛吃，猛吃就涨关注值——逼你分散、隐蔽。
2. **隐蔽 vs 速度**：慢操作隐蔽但耗时长，夜长梦多（AI 可能反水、事件可能爆发）。
3. **与 AI 博弈**：你洗盘，AI 可能识破反向护盘吸你的货；你拉升，AI 可能跟风后提前跑。
4. **T+1 的锁死感**：今天吸的筹明天才能用，今天追高的散户今天跑不掉——时机选择是真功夫。
5. **散户预期管理**：让散户跟风，又不能让他们在你出货前跑掉——出货是最高难度的艺术。
6. **资源约束**：资金有限，护盘和拉升要算计着花，不能无脑砸。
7. **（二期）信息战 vs 监管**：舆论操纵效率高但法律风险大，要权衡。
8. **（三期）逼空/做空博弈**：双向交易打开全新策略空间。

## 13. 开发分期与范围边界

### 13.1 第一期 POC（纯交易，可玩原型）

目标：验证核心交易循环是否好玩。

| 模块 | 包含 |
|------|------|
| 撮合引擎 | 完整订单簿、限价/市价/撤单、涨跌停、T+1 |
| 散户 | 4 群体（跟风/抄底/止损/价投）、聚合行为 |
| AI 主力 | 状态机 + 意图识别，1 个对手 |
| 监管 | 交易操纵类关注值 + 惩罚阶梯 |
| 时间 | 实时盘口 + 暂停只读 + 加速、数个交易日/关卡 |
| 关卡 | 单股单任务、难度递增、三星评分 |
| 复盘 | 时间轴回放、AI 内心独白、参与者视角 |
| UI | 五档盘口、下单、分时图、成交明细、监管条 |

### 13.2 第二期（信息战）

- 盘前/盘后操作界面
- 4 种舆论手段（小作文/水军/信息披露/制造热点）
- 舆论资源系统
- 信息违法类监管

### 13.3 第三期（双向交易）

- 融资融券（玩家/AI/散户全员）
- 做空闭环、爆仓、逼空
- 融资融券余额上限

### 13.4 远期（沙盒模式）

- 无固定目标，自由交易
- 多 AI 主力长期博弈
- 排行榜

### 13.5 明确不做（任何阶段）

- 集合竞价（开盘/收盘集合）
- 衍生品（期权/期货）
- 强化学习 AI
- 散户个体化建模
- 多股票 / 板块联动（远期可能）
