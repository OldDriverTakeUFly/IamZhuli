# 08 - 情绪系统与信息战

> 散户的行为由情绪驱动,而情绪可以被操纵。本文档描述多维情绪模型、消息冲击系统,以及盘后操纵的接入点。
>
> **这是二期信息战的 POC 地基**——先把情绪结构做对,后续水军造势/信号误导/消息监管联动才能自然接入。

## 1. 多维情绪模型(MarketSentiment)

**文件**:`src/IamZhuli.Simulation/Participants/RetailV2/MarketSentiment.cs`

### 1.1 为什么不是单维

原设计只有一个 0~1 的情绪标量(GreedFear),所有画像读同一个值。问题:
- 无法表达"散户对个股悲观但对大盘乐观"
- 消息面冲击没有注入点(NewsShock 是空桩)
- 所有画像对消息的反应一样(真实市场里,传闻只影响羊群,不影响价投)

### 1.2 四维情绪

| 维度 | 范围 | 含义 | 驱动方式 |
|------|------|------|----------|
| **GreedFear** | 0~1 (0=恐,1=贪) | 贪婪/恐惧(原 Value,价格驱动) | 每 tick 由 recentReturn 更新 |
| **Confidence** | 0~1 (0=悲观,1=乐观) | 对个股的信心/预期 | 消息面驱动,盘后冲击,次日缓慢衰减 |
| **HerdMood** | 0~1 (0=冷,1=热) | 群体热度(成交活跃度+情绪极端度) | 成交量+贪婪度组合 + 传闻 |
| **NewsBias** | -1~+1 | 消息面净偏差(利好+,利空-) | 盘后消息冲击写入 |

### 1.3 兼容性

保留 `Value/Greed/Fear/Extremity/IsPanic/IsEuphoric` 属性,内部映射 `GreedFear`。现有画像代码**零改动**。新维度通过新增属性暴露,画像可选消费。

### 1.4 日切衰减(DailyDecay)

```csharp
Confidence = Confidence * 0.6m + 0.5m * 0.4m;   // 信心向中性回归
HerdMood *= 0.5m;                                 // 群体热度消散
NewsBias *= 0.3m;                                 // 消息偏差大幅衰减(隔夜效应递减)
```

情绪不会永远被消息左右——睡一觉冷静了,信心回归中性,但消息偏差保留 30%(隔夜仍有余温)。

## 2. 消息冲击系统(NewsSystem)

**文件**:`src/IamZhuli.Simulation/MarketData/NewsSystem.cs`

### 2.1 四种消息类型

| 类型 | 成本 | 影响 | 效果 |
|------|------|------|------|
| **Positive 利好** | 免费 | Confidence↑, NewsBias+ | 跟风客更积极追涨 |
| **Negative 利空** | 免费 | Confidence↓, NewsBias- | 止损者更敏感、价投观望 |
| **Rumor 传闻** | 5千 | HerdMood↑(群体热度) | 只影响羊群/投机客,价投免疫 |
| **Pump 水军造势** | 2万/回合 | GreedFear↑(贪婪直接升) | 可累积叠加,持续渗透 |

### 2.2 消息的生命周期

- 消息有 `DurationTicks` 有效期(200~400 tick),期间持续施加衰减影响
- 每 tick 影响按 `decay = 1 - elapsed/duration` 衰减(前强后弱)
- 过期后影响消退,情绪自然回归价格驱动态
- 日切时未过期消息保留(隔夜效应),但 DailyDecay 让影响减弱

### 2.3 影响机制

```
利好 → NewsShock(positive, impact) → Confidence↑ + NewsBias+ + _target(贪婪)↑
利空 → NewsShock(negative, impact) → Confidence↓ + NewsBias- + _target(贪婪)↓
传闻 → ApplyNewsEffect(herd↑) → HerdMood↑(不改 NewsBias)
水军 → ApplyNewsEffect(greed_target↑) + NewsShock(small) → 贪婪目标直接升 + 小幅信心
```

## 3. 画像差异化消费

现有画像零改动就能跑(读 GreedFear 映射)。新增维度让画像**可选地**变聪明:

| 画像 | 新增维度消费 | 效果 |
|------|-------------|------|
| **激进跟风客** | `Confidence` 影响追涨门槛 | 信心高时门槛降低(利好后更容易追) |
| **止损者** | `NewsBias < 0` 时阈值再降 | 利空消息下止损更敏感(阈值×0.8) |
| **价投** | `NewsBias < -0.3` 时暂停买入 | 严重利空下价投也观望(概率减半) |
| 羊群型 | (预留)HerdMood 替代 Extremity | 群体热度直接驱动传染 |
| 机构 B | (预留)NewsBias 影响公允值 | 利好时上调公允值(愿意高位接货) |

## 4. 盘后操纵接入

### 4.1 盘后消息发布(已实现)

日终收盘后(`IsDayClosed` 暂停态),前端显示"盘后操作"面板:
```
📰 盘后操作 · 影响明日开盘情绪
[利好] [利空] [传闻(5k)] [水军(2w)]
当前消息偏差: +0.15 (偏多)
```

- 发布消息 → 扣成本(水军/传闻) → 注入 NewsSystem
- `StartNextDay` 时:消息系统日切 + 情绪 DailyDecay
- 次日开盘情绪已反映昨夜消息冲击

### 4.2 资金消耗

- 消息成本从玩家账户扣除(`Account.DebitCash`)
- 利好/利空免费(模拟公开新闻)
- 传闻 5000 元/条(放风/渠道费)
- 水军 20000 元/回合,可多回合累积(持续发帖)

### 4.3 API

```
POST /api/news?type=positive|negative|rumor|pump
→ { ok: true/false, error: "..." }
```

## 5. 被动资金流(PassiveFlow)

**文件**:`src/IamZhuli.Simulation/Participants/PassiveFlow.cs`

### 5.1 为什么需要

真实市场永远有一股"不看行情"的买盘兜底:指数 ETF 申赎、定投、养老金、社保。这些资金**无视涨跌**,每天按比例被动买入。原模型完全没有这个,导致阴跌阶段所有信号门控的买盘同时失效,市场死锁。

### 5.2 行为

- 每 tick 有 30% 概率市价买 1~3 手
- 日配额按流通盘 × 0.1%(200000 手 → 日买 200 手)
- 完全无视价格/情绪/趋势
- 资金充裕(聚合体,不跟踪盈亏)

这是治本的那一刀——阴跌不死锁的"底盘电流"。
